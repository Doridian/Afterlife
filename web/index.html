Afterlife

A native port of the LucasArts city-building game Afterlife (1996), running in your browser.

1. Get the CD

This site carries no game data. You need your own copy of the CD, which the Internet Archive has:

Afterlife on archive.org Download the CD (zip)

Unzip the download. You need the .bin file in it (the CD image; its .cue isn't needed).

2. Play

  1. Open the game and choose the .bin file (or the .iso of your own CD, or the CD's folder).
  2. Play. The game reads the files in your browser; nothing is uploaded anywhere.

The browser keeps the game files, so you only do this once per browser.

Play Afterlife

About

Afterlife is a decompilation and native port to portable C and SDL3, for Linux, macOS and the web. The source, and the desktop builds, are on GitHub.

Saved games can be dragged onto the game window, and downloaded from the game's File menu.

An unofficial port of the 1996 LucasArts game. The game data is not included.
